# Blender authoring sources

`Environment/` contains the café master, the six historical scripts and original Unity export. `FemaleCharacter/` contains the earlier white-dress rig and its source workflow. `ConnectionProbe/` is the early BlenderBalls transfer experiment.

The reusable boy lives at `../Characters/Boy_GreenSweater/`. Open the standalone boy master for the rest-pose rig/actions. Its café copy uses a linked character library; keep those files together or relink when opening elsewhere.

These are recovered historical sources. Generators contain absolute authoring-Mac paths and some clear scenes; do not run them against a finished active scene unchanged. See [Codex + Blender](../Docs/CODEX_BLENDER.md), [visual pipeline](../Docs/VISUAL_PIPELINE.md) and [history](../Docs/Doro-Project-History/README.md).
